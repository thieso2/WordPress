## 1. The headline finding — a 23-module cycle 🟢

The dependency graph is **not a DAG**. Tarjan's algorithm finds a strongly connected component
containing **23 of the 44 modules**:

```
admin-application · authentication-and-sessions · block-editor · block-supports ·
bootstrap-and-load · cron · error-handling-and-recovery-mode · filesystem-api ·
formatting-and-sanitization · global-styles-theme-json · http-api · internationalization ·
kses-security · multisite · options-and-transients · posts-and-post-types · query-and-loop ·
rewrite-and-permalinks · script-modules-and-assets · taxonomy-and-terms · themes-and-templates ·
updates-and-upgrader · users-roles-capabilities
```

**Every module in this set can reach every other one.** A change to any of the 23 has a transitive
blast radius covering the entire component plus everything downstream of it.

### Representative cycles 🟢

| Cycle | Why it exists |
|-------|--------------|
| `bootstrap-and-load` ↔ `error-handling-and-recovery-mode` | The fatal handler is registered *during* boot (line 69) and reads paused extensions *from* boot (BR-BOOT-05). |
| `formatting-and-sanitization` ↔ `kses-security` | `wp_kses()` calls formatting helpers; `sanitize_*()` calls KSES. |
| `posts-and-post-types` ↔ `taxonomy-and-terms` | Posts register taxonomies; taxonomies count posts and query by `post_status = 'publish'` (BR-TAX-11). |
| `users-roles-capabilities` ↔ `posts-and-post-types` | `map_meta_cap('edit_post')` reads the post; posts have `post_author`. |
| `rewrite-and-permalinks` ↔ `query-and-loop` | `WP::parse_request()` reads rewrite rules; `wp_unique_post_slug()` reads `$wp_rewrite->pagination_base` and `->feeds` (BR-POST-07). |
| `options-and-transients` → `formatting` → `kses` → `users-roles-capabilities` → `options` | `sanitize_option()` on every write; capability checks read options. |

**Consequence for specification:** the 23 modules **cannot be specified independently**. A
specification of `posts-and-post-types` that does not also state `rewrite-and-permalinks`'
`pagination_base` and `taxonomy-and-terms`' publish-only counting is incomplete.

## 3. Foundation modules — the true leaves 🟢

Four modules depend on **nothing** internal. Changes here propagate everywhere; nothing propagates in.

| Module | Direct dependents | Character |
|--------|:-----------------:|-----------|
| `hooks-plugin-api` | **32** | Every dispatch in the system. Highest-impact module in WordPress. |
| `cache-and-object-cache` | **14** | Silently changes transient storage, cron locking and query splitting. |
| `html-api` | 3 | Used by `media`, `interactivity-api`, `block-editor`. Self-contained. |
| `style-engine` | 2 | Used by `block-supports`, `global-styles`. The cleanest boundary in core. |

`html-api` and `style-engine` are the only two modules in WordPress with **both** zero internal
dependencies **and** a small dependent set. They are the only genuinely extractable components.

---

## 4. Terminal modules — safe to change in isolation 🟢

Nine modules have **no dependents at all**:

`embeds-oembed` · `blocks-library` · `xmlrpc` · `feeds` · `sitemaps` ·
`ai-abilities-connectors` · `performance-speculation-view-transitions` · `site-health` ·
`deprecated-compat`

A change to any of these affects only itself. **`xmlrpc` being terminal is significant**: it can be
disabled or removed without breaking any other module (TD-03).

## 6. Cross-module coupling that is invisible locally 🟢

These are the couplings the Detective found where a rule in one module **causes** a rule in another.
They do not appear in the dependency graph.

| Coupling | Mechanism |
|----------|-----------|
| `posts-and-post-types` → `database-wpdb` | Drafts store `0000-00-00 00:00:00` (BR-POST-04), which is **why** `NO_ZERO_DATE` is stripped from the SQL mode (BR-DB-10). See ADR-007. |
| `rewrite-and-permalinks` → `posts-and-post-types` | `pagination_base = 'page'` and `$wp_rewrite->feeds` determine which post slugs are legal (BR-POST-07). |
| `options-and-transients` → `rewrite`, `cron` | The 150 KB autoload threshold (BR-OPT-06) can silently de-autoload the routing table or the cron queue (F-RW-02, F-CRON-03). |
| `cache-and-object-cache` → `options`, `cron`, `query` | A persistent cache changes transient storage (BR-OPT-10), cron lock semantics (F-CRON-02) and split-query eligibility (BR-QUERY-07). |
| `comments` → `bootstrap-and-load` | Whether a disallowed comment becomes `trash` or `spam` depends on `EMPTY_TRASH_DAYS` (BR-CMT-10). |
| `taxonomy-and-terms` → `posts-and-post-types` | Term counts include only `post_status = 'publish'` (BR-TAX-11), so a status change silently changes a count. |
| `authentication-and-sessions` → all nonces | Session token destruction invalidates every outstanding nonce (BR-AUTH-15). |
| `block-supports` → registration order | Space-concatenated attribute merge means registration order affects emitted class order (F-BSUP-01). |

## 7. Findings

| # | Finding | Confidence |
|---|---------|-----------|
| F-SIM-01 | **23 of 44 modules form one strongly connected component.** WordPress's kernel is not layered; it is a mutually-dependent core with a thin shell of terminal modules around it. | 🟢 |
| F-SIM-02 | `hooks-plugin-api` has 32 direct dependents — more than double any other module. It is the single highest-impact change surface in WordPress. | 🟢 |
| F-SIM-03 | `html-api` and `style-engine` are the only modules with zero internal dependencies **and** few dependents. They are the only components that could be extracted as libraries. | 🟢 |
| F-SIM-04 | `xmlrpc` has **zero dependents**. Nothing in WordPress requires it. Its continued presence is a compatibility decision (ADR-002), not a structural one. | 🟢 |
| F-SIM-05 | The most consequential couplings (draft dates ↔ SQL mode; pagination base ↔ legal slugs; autoload threshold ↔ router) are **invisible from either module alone**. Specifications written per-module will miss all of them. | 🟢 |
| F-SIM-06 | Nine terminal modules — including all four inbound/outbound interface modules except REST — can be specified and changed independently. That is where safe change lives. | 🟢 |
