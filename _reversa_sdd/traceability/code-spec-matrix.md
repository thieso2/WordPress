| **Unmapped (89 files)** | Listed in §3 | Mostly small helpers, deprecated shims and files whose primary module was already covered by a sibling. Candidates for a follow-up pass. |

## 6. Reading this matrix

- **🟢** — the file is named in a unit's `primary_files` or is the source of a catalogued function.
  Every business rule citing it appears in that unit's `requirements.md`.
- **🟡** — the file was attributed to a unit by directory convention. Its behaviour is covered by
  the unit's rules, but no individual function from it was catalogued.
- **`n/a`** — deliberately out of scope; see §5.
