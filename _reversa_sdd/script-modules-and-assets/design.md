## Main Flow

1. **recursive topological dependency resolution** — all_deps() walks handles, computes missing deps via array_diff against the registry, recurses into declared deps, and appends survivors to to_do. Failure aborts a branch during recursion but only skips one handle at the top level.
   Source: `wp-includes/class-wp-dependencies.php:193` 🟢
2. **monotonic group promotion** — set_group() writes only when the new group is strictly lower than the recorded one, so a handle can move footer->header but never header->footer.
   Source: `wp-includes/class-wp-dependencies.php:511` 🟢
3. **dependents-derived fetch priority** — get_highest_fetchpriority() consults dependents_map so a module used by a high-priority module inherits urgency.
   Source: `wp-includes/class-wp-script-modules.php:477` 🟢
4. **once-per-handle warning** — Missing-dependency notices are recorded in a private array so repeated resolutions do not spam the log.
   Source: `wp-includes/class-wp-dependencies.php:220` 🟢

## Alternative Flows

- **BR-ASSET-03:** Inside recursion a resolution failure returns false and aborts that branch; at the top level it skips only that handle and continues. 🟢
- **BR-ASSET-04:** set_group() only ever moves a handle to a lower group number: footer to header, never the reverse. 🟢
- **BR-ASSET-06:** A handle already in done is never re-emitted. 🟢

## Risks and Gaps

- 🟢 **F-ASSET-01** — The footer-to-header promotion rule makes $in_footer advisory: any header-loaded dependent silently pulls a script into the head.
- 🟢 **F-ASSET-02** — A missing dependency causes silent omission rather than an error; before the 6.9.1 notice there was no diagnostic at all.
- 🟡 **F-ASSET-03** — There is no explicit cycle detection in all_deps(); circular dependencies rely on the queued/group short-circuits and can otherwise recurse to the stack limit.
- 🟢 **F-ASSET-04** — Two complete asset systems coexist with no shared abstraction; a dependency cannot span the classic and module registries.
- 🟢 **F-ASSET-05** — script-loader.php is a 4000-line hand-maintained registry with versions as string literals, the only place bundled JS versions can be discovered.
- 🟢 **F-ASSET-06** — Computing fetch priority from dependents is a genuinely modern touch: a module used by a high-priority module inherits urgency automatically.
