## Overview

Register, resolve dependencies for, and emit scripts and stylesheets. Two generations coexist: the classic WP_Dependencies handle system and WP_Script_Modules with ES modules and import maps. 🟢

**Complexity:** `medium` · **Business rules extracted:** 10 · **Public functions catalogued:** 11 · **Extension points:** 13

**Depended on by 4 module(s):** `block-editor`, `interactivity-api`, `internationalization`, `performance-speculation-view-transitions`

## Responsibilities

- **recursive topological dependency resolution** — all_deps() walks handles, computes missing deps via array_diff against the registry, recurses into declared deps, and appends survivors to to_do. Failure aborts a branch during recursion but only skips one handle at the top level 🟢
- **monotonic group promotion** — set_group() writes only when the new group is strictly lower than the recorded one, so a handle can move footer->header but never header->footer 🟢
- **dependents-derived fetch priority** — get_highest_fetchpriority() consults dependents_map so a module used by a high-priority module inherits urgency 🟢
- **once-per-handle warning** — Missing-dependency notices are recorded in a private array so repeated resolutions do not spam the log 🟢
