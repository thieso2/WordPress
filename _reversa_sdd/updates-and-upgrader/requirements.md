## Overview

Check for, download, verify and install core, plugin, theme and translation updates, and migrate the database schema between versions. 🟢

**Complexity:** `high` · **Business rules extracted:** 9 · **Public functions catalogued:** 8 · **Extension points:** 11

**Depended on by 3 module(s):** `admin-application`, `filesystem-api`, `site-health`

## Responsibilities

- **escalating check backoff** — Timeout rises from 1 minute during cron through 1 hour and 2 hours to 12 hours in steady state, so a failing update endpoint costs one slow request per hour rather than one per page view 🟢
- **diff-based schema migration** — dbDelta() compares wp_get_db_schema()'s CREATE TABLE statements with the live schema and emits ALTER statements; data migrations that cannot be expressed as schema shape live in version-gated upgrade_NNN() functions 🟢
- **download-verify-unpack-install pipeline** — download_package with signature verification, unpack via ZipArchive or PclZip, install_package under maintenance mode, with per-version file manifests for core cleanup 🟢
