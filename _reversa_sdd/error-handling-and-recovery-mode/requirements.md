## Overview

Survive a fatal PHP error: catch it, identify which plugin or theme caused it, pause that extension, and email the administrator a link to a mode where the site loads without it. 🟢

**Complexity:** `medium` · **Business rules extracted:** 10 · **Public functions catalogued:** 9 · **Extension points:** 6

**Depended on by 1 module(s):** `bootstrap-and-load`

## Responsibilities

- **detect-attribute-pause-recover loop** — register_shutdown_function catches the fatal, the error's file path maps to a plugin or theme, the extension is stored as paused, an email with a signed link is sent, and the boot sequence skips the paused extension on subsequent requests 🟢
- **lockout-proof TTL constraint** — get_link_ttl() returns max(filtered_ttl, rate_limit) so a misconfigured filter cannot make links expire faster than replacements can be sent 🟢
