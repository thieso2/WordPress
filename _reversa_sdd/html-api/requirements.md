## Overview

Parse and modify HTML correctly in PHP without a DOM. Two layers: a streaming tag-level editor and a full HTML5-spec-compliant tree-construction parser. 🟢

**Complexity:** `high` · **Business rules extracted:** 7 · **Public functions catalogued:** 13 · **Extension points:** 0

**Depended on by 3 module(s):** `block-editor`, `interactivity-api`, `media-and-attachments`

## Responsibilities

- **streaming byte-level editing** — Forward-only scan recording queued replacements applied on get_updated_html(); memory proportional to the document, not to a node graph 🟢
- **bookmark and seek** — Named positions saved during a forward scan allow non-linear editing on a forward-only cursor 🟢
- **HTML5 tree construction** — Insertion modes, stack of open elements, list of active formatting elements and the adoption agency algorithm, per the HTML5 specification 🟢
