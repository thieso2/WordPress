## Overview

Run many sites from one installation, sharing users and a codebase while separating content. 🟢

**Complexity:** `high` · **Business rules extracted:** 8 · **Public functions catalogued:** 7 · **Extension points:** 11

**Depended on by 1 module(s):** `users-roles-capabilities`

## Responsibilities

- **table-prefix site isolation** — Blog-scoped tables are prefixed per blog id while users, usermeta and the ms-global tables are shared; set_blog_id() recomputes only the blog-scoped names 🟢
- **stacked blog switching** — switch_to_blog pushes onto a stack and updates wpdb prefix, object cache blog prefix and assorted globals; restore_current_blog pops. An unbalanced switch corrupts every subsequent query 🟢
