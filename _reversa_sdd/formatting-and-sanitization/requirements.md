## Responsibilities

- **context-specific output escaping** — A distinct escaper per output context (HTML text, attribute, URL-in-markup, raw URL, JS, textarea, XML), applied at render rather than at storage 🟢
- **regex typographic transformation** — wpautop and wptexturize transform rendered HTML with regular expressions while maintaining skip-lists for block-level and code tags 🟢
