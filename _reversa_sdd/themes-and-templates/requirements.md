## Overview

Choose which PHP or HTML file renders the current query, and manage theme registration, parent/child inheritance and theme features. 🟢

**Complexity:** `medium` · **Business rules extracted:** 14 · **Public functions catalogued:** 9 · **Extension points:** 11

**Depended on by 5 module(s):** `block-editor`, `customizer`, `feeds`, `global-styles-theme-json`, `script-modules-and-assets`

## Responsibilities

- **ordered conditional hierarchy** — 17 is_* conditionals tested in a fixed order; the first true one selects its getter, which builds a most-specific-first candidate filename list 🟢
- **three-location template lookup** — For each candidate filename in order: child theme path, parent theme path (only when a child is active), then wp-includes/theme-compat/. Breaks on first hit, so filename specificity beats location 🟢
- **conditional urldecode variant** — A percent-decoded filename candidate is inserted only when decoding actually changes the string, avoiding duplicate candidates for ASCII slugs 🟢
- **post-filter inclusion guard** — realpath() resolution, .php/.html extension allowlist, is_file and is_readable checks after template_include, preventing local file inclusion via the filter 🟢
