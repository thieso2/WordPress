## Main Flow

1. **ordered conditional hierarchy** — 17 is_* conditionals tested in a fixed order; the first true one selects its getter, which builds a most-specific-first candidate filename list.
   Source: `wp-includes/template-loader.php:24` 🟢
2. **three-location template lookup** — For each candidate filename in order: child theme path, parent theme path (only when a child is active), then wp-includes/theme-compat/. Breaks on first hit, so filename specificity beats location.
   Source: `wp-includes/template.php` 🟢
3. **conditional urldecode variant** — A percent-decoded filename candidate is inserted only when decoding actually changes the string, avoiding duplicate candidates for ASCII slugs.
   Source: `wp-includes/template.php` 🟢
4. **post-filter inclusion guard** — realpath() resolution, .php/.html extension allowlist, is_file and is_readable checks after template_include, preventing local file inclusion via the filter.
   Source: `wp-includes/template-loader.php:59` 🟢

## Alternative Flows

- **BR-TPL-01:** template_redirect fires only when wp_using_themes() is true. 🟢
- **BR-TPL-02:** A HEAD request exits immediately after template_redirect unless the exit_on_http_head filter says otherwise. 🟢
- **BR-TPL-03:** robots, favicon, feed and trackback requests are handled before the hierarchy and even when themes are disabled. 🟢
- **BR-TPL-08:** Lookup order per filename is child theme, then parent theme only if a child is active, then wp-includes/theme-compat/. 🟢
- **BR-TPL-10:** A urldecoded template-name variant is added to the candidate list only when it differs from the raw name. 🟢
- **BR-TPL-11:** A post's custom template slug from post meta is used only if validate_file() returns 0. 🟢

## Risks and Gaps

- 🟢 **F-TPL-01** — The template hierarchy is not a data structure but the evaluation order of 17 conditionals plus per-type candidate arrays; it cannot be introspected, only read.
- 🟢 **F-TPL-02** — template_include returns a filesystem path that is then included; the four-check guard after it is load-bearing security, not defensive style.
- 🟢 **F-TPL-03** — Filename specificity beating theme location means a child theme cannot override a parent's more-specific template with a less-specific one.
- 🟢 **F-TPL-04** — Child functions.php loads before the parent's while child templates are found before the parent's: two opposite orderings for the same relationship, each correct for its purpose.
- 🟡 **F-TPL-05** — theme-compat/ is a third, largely invisible template source that most theme developers never learn about.
- 🟢 **F-TPL-06** — validate_file() on the meta-supplied template slug is the only thing stopping post meta from selecting an arbitrary file.
