## Overview

Keep code written for WordPress 1.5 working on WordPress 7.2, and polyfill newer PHP functions so core can use modern syntax on PHP 7.4. 🟢

**Complexity:** `low` · **Business rules extracted:** 6 · **Public functions catalogued:** 6 · **Extension points:** 5

**Depended on by 0 module(s):** _none — terminal module_

## Responsibilities

- **functional deprecation** — The deprecated function keeps working and merely calls _deprecated_function(), which emits a notice only under WP_DEBUG 🟢
- **listener-gated hook deprecation** — apply_filters_deprecated()/do_action_deprecated() emit their notice only when a callback is registered, so unused deprecated hooks stay silent 🟢
