## Main Flow

1. **vendored-library integration by substitution** — SimplePie's HTTP transport is replaced by WP_SimplePie_File (routing through the WP HTTP API) and its sanitizer by WP_SimplePie_Sanitize_KSES, so the library's two riskiest behaviors use core's audited implementations.

## Risks and Gaps

- 🟢 **F-FEED-01** — Routing SimplePie through the WP HTTP API and KSES is exactly the right integration: a vendored library's network access and HTML output are both replaced with core's audited implementations.
- 🟡 **F-FEED-02** — Four output formats are maintained for a feature whose consumers have largely consolidated on RSS 2.0 and Atom.
- 🟢 **F-FEED-03** — Feed templates being ordinary PHP means a plugin filtering the_content also alters feed output, the most common cause of malformed feeds.
