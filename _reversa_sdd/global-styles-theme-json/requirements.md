## Overview

A declarative styling system. theme.json describes settings (what the editor offers) and styles (what is applied), merged across four origins and compiled to CSS. 🟢

**Complexity:** `high` · **Business rules extracted:** 10 · **Public functions catalogued:** 9 · **Extension points:** 6

**Depended on by 3 module(s):** `block-editor`, `block-supports`, `themes-and-templates`

## Responsibilities

- **four-origin cascade with early exit** — merge core, then block, then theme, then user data, returning early at the requested origin so callers can obtain pre-user-customization state 🟢
- **schema-as-constants** — Valid settings, styles, properties, protected properties, elements and pseudo-selectors are all declared as class constants: a formal data model expressed in PHP arrays 🟢
- **viewport breakpoint validation** — is_valid_viewport_breakpoint_size, get_viewport_breakpoint_value_in_pixels and sanitize_viewport_settings validate theme-supplied breakpoints before they become media queries 🟢
