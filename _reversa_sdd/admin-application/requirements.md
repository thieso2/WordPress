## Responsibilities

- **shared bootstrap gate** — admin.php defines the admin context constants, loads WordPress, requires the admin includes, and calls auth_redirect() once before firing admin_init, so every screen inherits authentication 🟢
- **action-name ajax dispatch** — $_REQUEST['action'] selects wp_ajax_{action} for logged-in users or wp_ajax_nopriv_{action} for anonymous ones; the nopriv variant IS the authorization model 🟢
