## Overview

Two legacy content-placement systems that predate blocks and remain load-bearing: sidebar widgets and navigation menus. 🟢

**Complexity:** `medium` · **Business rules extracted:** 11 · **Public functions catalogued:** 10 · **Extension points:** 14

**Depended on by 1 module(s):** `customizer`

## Responsibilities

- **multi-instance single-option storage** — One WP_Widget subclass serves many placed widgets; all instance settings live in one option row keyed by number, with _register() iterating stored numbers to call _register_one() 🟢
- **meta-driven menu item model** — A menu item's type, target object, parent and presentation all live in nine post meta rows; the post row itself carries only ordering and an optional title override 🟢
- **orphan tombstoning** — _menu_item_orphaned flags items whose referenced object was deleted, standing in for a foreign key the schema lacks 🟢
