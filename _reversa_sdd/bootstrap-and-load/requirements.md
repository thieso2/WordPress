## Overview

Turn a bare PHP request into a fully initialized WordPress runtime: locate configuration, verify host requirements, define constants, connect the database, start the object cache, load plugins and the theme, hand off to the request handler. 🟢

**Complexity:** `high` · **Business rules extracted:** 10 · **Public functions catalogued:** 15 · **Extension points:** 12

**Depended on by 4 module(s):** `admin-application`, `error-handling-and-recovery-mode`, `multisite`, `updates-and-upgrader`

## Responsibilities

- **config discovery** — Two-location search for wp-config.php with a guard preventing a nested WordPress from stealing its parent's config 🟢
- **maintenance window self-heal** — Four sequential escape conditions; a stale .maintenance older than 10 minutes is ignored 🟢
- **memoized whitelist resolution** — Environment type and development mode both resolve once into a static and fall back to a safe default on any unrecognized value 🟢
- **paused-extension filtering** — Plugins/themes that fataled are removed from the active list before loading 🟢
