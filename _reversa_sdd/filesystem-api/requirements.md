## Overview

Write files portably, including on hosts where PHP cannot write directly and must go through FTP or SSH; plus Ed25519 verification of update packages. 🟢

**Complexity:** `high` · **Business rules extracted:** 11 · **Public functions catalogued:** 5 · **Extension points:** 5

**Depended on by 5 module(s):** `admin-application`, `internationalization`, `media-and-attachments`, `rewrite-and-permalinks`, `updates-and-upgrader`

## Responsibilities

- **ownership-based method detection** — Write a temp file, compare fileowner() of that file with fileowner() of a WordPress file; only if they match is direct writing used. 'Can write' and 'should write' are treated as different questions 🟢
- **degradable signature verification** — Missing crypto yields 'unsupported' rather than 'invalid' so old hosts can still update; the pure-PHP polyfill is speed-tested first to avoid exhausting max_execution_time 🟢
