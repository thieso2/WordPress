## Overview

WordPress's key-value store. Site configuration, plugin settings, cached remote data and expiring values all live in wp_options addressed by name. Read on every request via wp_load_alloptions(), making its caching behavior the largest single lever on WordPress performance. 🟢

## Responsibilities

- **five-level option read cascade** — pre_option filters -> alloptions bulk cache -> notoptions negative cache -> per-option object cache -> single-row SELECT. Misses are recorded in notoptions so they never re-query 🟢
- **automatic autoload sizing** — Serialized values over 150000 bytes are demoted to auto-off, protecting every request from a single oversized autoloaded option 🟢
- **two-row transient with lazy expiry** — Value and timeout stored as separate option rows; expiry checked on read, both rows deleted when stale. Repairs a missing timeout row by recreating both 🟢
- **autoload-as-expiry-proxy** — get_transient() uses presence in alloptions to infer the transient has no timeout, avoiding a timeout lookup. Couples the autoload flag to transient semantics 🟢
