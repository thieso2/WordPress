## Main Flow

1. **layered SSRF validation** — Type and scheme check, sanitize-and-compare round trip, structural rejections (userinfo, special host characters), same-host exemption, DNS resolution with 13 blocked IPv4 ranges, then a three-port allowlist.
   Source: `wp-includes/http.php:559` 🟢
2. **sanitize-as-validator** — wp_kses_bad_protocol() output is compared case-insensitively against the original; any difference rejects the URL rather than using the cleaned form.
   Source: `wp-includes/http.php:565` 🟢
3. **capability-based transport negotiation** — _get_first_available_transport() selects cURL or streams per request based on SSL, proxy and streaming requirements.
   Source: `wp-includes/class-wp-http.php:547` 🟢

## Alternative Flows

- **BR-HTTP-01:** Only wp_safe_remote_* validates the URL; wp_remote_* does not. 🟢
- **BR-HTTP-02:** Only http and https schemes are accepted. 🟢
- **BR-HTTP-03:** If wp_kses_bad_protocol() changes the URL in any way it is rejected rather than corrected: sanitization used as detection. 🟢
- **BR-HTTP-10:** With an explicit port only 80, 443 and 8080 are allowed, filterable via http_allowed_safe_ports. 🟢

## Risks and Gaps

- 🟢 **F-HTTP-01** — The most carefully written security function in WordPress: the range list is annotated with RFC intent and the 169.254.0.0/16 comment names cloud metadata explicitly, evidence of threat-model-driven design.
- 🟢 **F-HTTP-02** — The sanitize-then-compare pattern (reject if changed rather than use the cleaned value) is the correct way to use a sanitizer as a validator and is rare in the codebase.
- 🟡 **F-HTTP-03** — Validation is by resolved IP but the request is made by hostname; a DNS entry resolving differently between check and request (DNS rebinding) defeats the guard, and nothing pins the resolved address.
- 🟡 **F-HTTP-04** — Only IPv4 is range-checked. IPv6 literals are rejected outright, but a hostname resolving to IPv6 is not checked because gethostbyname() returns IPv4 only.
- 🟢 **F-HTTP-05** — Safety is opt-in by function name, and the API makes the unsafe call the shorter and more obvious one.
- 🟡 **F-HTTP-06** — The same-host exemption means a site whose home option points at an internal hostname can be used to reach that host.
