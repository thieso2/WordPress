## Main Flow

1. **cover-fit crop geometry** — size_ratio = max(new_w/orig_w, new_h/orig_h) yields a source rectangle covering the destination box; offsets from left/right/top/bottom keywords or centered with floor().
   Source: `wp-includes/media.php:555` 🟢
2. **upscale prevention** — Three-branch guard on which destination dimensions were supplied; any request larger than the original returns false.
   Source: `wp-includes/media.php:568` 🟢
3. **fuzzy aspect matching** — Scale the larger image down to the smaller one's width, then compare within a 1px tolerance via wp_fuzzy_number_match().
   Source: `wp-includes/media.php:738` 🟢
4. **srcset candidate filtering** — Same-directory guard, is_src detection, 2048px width cap with an is_src exemption, and fuzzy ratio match.
   Source: `wp-includes/media.php:1444` 🟢
5. **capability-negotiated editor selection** — Loop over Imagick then GD, testing test(), supports_mime_type() and required methods; memoized by md5 of args plus implementations.
   Source: `wp-includes/media.php:4430` 🟢

## Alternative Flows

- **BR-MEDIA-01:** WordPress never upscales: a requested size larger than the original returns false and the original is used. 🟢
- **BR-MEDIA-05:** srcset candidates wider than 2048px (max_srcset_image_width filter) are excluded unless the candidate is the src image itself. 🟢

## Risks and Gaps

- 🟢 **F-MEDIA-01** — The most algorithmically dense module in core and one of the few with genuinely non-trivial mathematics; the crop geometry is correct and well-guarded.
- 🟢 **F-MEDIA-02** — Storage grows multiplicatively with registered sizes: N subsizes per upload, with no deduplication and no lazy generation in core.
- 🟢 **F-MEDIA-03** — The 1-pixel fuzzy match is a workaround for rounding in the resize pipeline, meaning aspect-ratio identity is approximate throughout the media layer.
- 🟢 **F-MEDIA-04** — Injecting responsive attributes at render time means the same stored content produces different HTML across WordPress versions: good for upgrades, bad for output reproducibility.
- 🟢 **F-MEDIA-05** — The wp_image_editors filter can substitute an arbitrary class into the image pipeline with only duck-typed test() and supports_mime_type() checks.
