## Overview

Upload handling, image resizing, responsive image markup and media metadata. The largest body of pure algorithmic code in WordPress: geometry, aspect-ratio matching and srcset generation. 🟢

**Complexity:** `high` · **Business rules extracted:** 10 · **Public functions catalogued:** 11 · **Extension points:** 12

**Depended on by 1 module(s):** `xmlrpc`

## Responsibilities

- **cover-fit crop geometry** — size_ratio = max(new_w/orig_w, new_h/orig_h) yields a source rectangle covering the destination box; offsets from left/right/top/bottom keywords or centered with floor() 🟢
- **upscale prevention** — Three-branch guard on which destination dimensions were supplied; any request larger than the original returns false 🟢
- **fuzzy aspect matching** — Scale the larger image down to the smaller one's width, then compare within a 1px tolerance via wp_fuzzy_number_match() 🟢
- **srcset candidate filtering** — Same-directory guard, is_src detection, 2048px width cap with an is_src exemption, and fuzzy ratio match 🟢
- **capability-negotiated editor selection** — Loop over Imagick then GD, testing test(), supports_mime_type() and required methods; memoized by md5 of args plus implementations 🟢
