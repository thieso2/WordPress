## Overview

Declarative client-side interactivity driven by data-wp-* HTML attributes, with server-side pre-rendering of directives so the initial HTML is already correct. 🟢

**Complexity:** `high` · **Business rules extracted:** 7 · **Public functions catalogued:** 10 · **Extension points:** 2

**Depended on by 1 module(s):** `blocks-library`

## Responsibilities

- **server-side directive processing** — Walk the HTML with the directives processor, dispatching each recognized data-wp-* attribute to a handler called on both element entry and exit so context frames push and pop correctly 🟢
- **namespaced reference resolution** — parse_directive_name splits directive from suffix; extract_directive_value parses namespace::path with a default namespace; evaluate() walks namespace then path honouring a ! negation prefix 🟢
- **non-destructive style merging** — merge_style_property parses the existing style attribute, replaces one property and re-serializes, so directives compose with author-written inline styles 🟢
