## Overview

Live-preview theme and site settings with a changeset that can be saved, scheduled or discarded. Superseded by the Site Editor for block themes but still the settings surface for classic themes. 🟢

**Complexity:** `high` · **Business rules extracted:** 8 · **Public functions catalogued:** 11 · **Extension points:** 10

**Depended on by 1 module(s):** `widgets-and-nav-menus`

## Responsibilities

- **four-level registry** — Panel contains Section contains Control which writes Setting; controls are UI and settings are storage, in a many-to-many relationship 🟢
- **changeset as a post** — Unsaved state is serialized into a customize_changeset post keyed by UUID rather than a session, enabling shareable preview links and scheduled publication 🟢
- **three-stage value pipeline** — validate_callback rejects, sanitize_callback cleans for storage, sanitize_js_callback prepares for the JS preview 🟢
