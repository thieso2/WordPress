## Main Flow

1. **provider registry with paginated index** — An abstract provider yields URL lists; the registry holds providers; the index builds a sitemap-of-sitemaps paginated at 2000 URLs per file, well under the 50000 protocol limit.
   Source: `wp-includes/sitemaps/class-wp-sitemaps-index.php` 🟢

## Alternative Flows

- **BR-SM-04:** Only public post types and public taxonomies are included. 🟢
- **BR-SM-05:** The user provider includes only authors with published posts. 🟢

## Dependencies

- `posts-and-post-types` — The central content entity 🟢
- `taxonomy-and-terms` — Classify objects via a three-table design (wp_terms, wp_term_taxonomy, wp_term_relationships) that separates the word from the classification from the assignment 🟢
- `users-roles-capabilities` — The authorization model 🟢
- `rewrite-and-permalinks` — Two inverse operations: compile a permalink structure into regex rules mapping URLs to query variables, and generate URLs from objects 🟢
- `query-and-loop` — Turn a URL into a set of posts 🟢

**Depended on by:** _none_

## Identified Design Decisions

| Decision | Evidence in the code | Confidence |
|----------|----------------------|------------|
| An abstract provider yields URL lists; the registry holds providers; the index builds a sitemap-of-sitemaps paginated at 2000 URLs per file, well under the 50000 protocol limit | `wp-includes/sitemaps/class-wp-sitemaps-index.php` | 🟢 |
| Three built-in providers cover posts, taxonomies and users | `wp-includes/sitemaps/providers/` | 🟢 |
| Each sitemap file holds at most 2000 URLs, filterable per object type via wp_sitemaps_max_urls | `wp-includes/sitemaps.php:90` | 🟢 |
| An XSL stylesheet is served so the raw XML renders readably in a browser | `wp-includes/sitemaps/class-wp-sitemaps-stylesheet.php` | 🟢 |
| Only public post types and public taxonomies are included | `wp-includes/sitemaps/providers/class-wp-sitemaps-posts.php` | 🟢 |
| The user provider includes only authors with published posts | `wp-includes/sitemaps/providers/class-wp-sitemaps-users.php` | 🟢 |
