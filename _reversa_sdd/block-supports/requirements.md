## Overview

Cross-cutting block features. A block declares supports in block.json and this module injects the resulting classes and inline styles at render time, so no block implements colour or spacing handling itself. 🟢

**Complexity:** `medium` · **Business rules extracted:** 6 · **Public functions catalogued:** 4 · **Extension points:** 2

**Depended on by 2 module(s):** `block-editor`, `blocks-library`

## Responsibilities

- **space-concatenation attribute merge** — Each support's apply callback returns attributes; scalars (excluding booleans) are appended space-separated to any existing value for the same attribute name, letting 23 modules compose without coordination 🟢
