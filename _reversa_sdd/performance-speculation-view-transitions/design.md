## Risks and Gaps

- 🟢 **F-PERF-01** — prefetch plus conservative as the default is correct: prerender runs the target page's scripts speculatively, which would distort analytics and trigger side effects for pages never visited.
- 🟢 **F-PERF-02** — An explicit hosting-provider override channel is unusual in core, which normally recognizes only site owners and plugin authors as configuration actors.
- 🟡 **F-PERF-03** — View Transitions ships infrastructure ahead of the feature: config classes exist before there is much to configure.
