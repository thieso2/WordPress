## Overview

Turn a bare URL on its own line into rich embedded content, and expose WordPress's own posts as oEmbed providers. 🟢

**Complexity:** `medium` · **Business rules extracted:** 8 · **Public functions catalogued:** 9 · **Extension points:** 9

**Depended on by 0 module(s):** _none — terminal module_

## Responsibilities

- **provider registry match** — 59 pattern => [endpoint, is_regex] pairs matched with preg_match; sanitize_provider() validates each entry 🟢
- **link-rel discovery fallback** — HTTP GET the target URL and scrape <link rel="alternate" type="application/json+oembed"> or its XML variant. A server-side request to a user-supplied URL 🟢
- **format negotiation** — _fetch_with_format('json') then fall back to 'xml' 🟢
- **type-dispatched rendering** — photo renders a validated img tag; video and rich inject provider html; link renders an anchor 🟢
