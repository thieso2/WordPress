## Risks

- 🟢 **F-EMB-01** — Discovery makes a server-side HTTP request to a user-supplied URL; its safety depends entirely on the HTTP API's SSRF guards, not on anything in this module.
- 🟢 **F-EMB-02** — rich and video responses inject third-party HTML into the page. The trust boundary is the provider allowlist, so the 59-entry registry rather than sanitization is the actual security control.
- 🟢 **F-EMB-03** — Explicitly disabling XXE in _parse_xml() is one of the few places core defends against a parser-level attack.
- 🟡 **F-EMB-04** — Using a post type as the embed cache means embed data participates in post queries, revisions and exports.
