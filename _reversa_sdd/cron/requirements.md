## Overview

Schedule deferred and recurring work. WordPress has no daemon; cron is a queue in an option, drained by piggybacking on incoming HTTP requests. 🟢

## Responsibilities

- **asymmetric duplicate window** — For events due within 10 minutes or already past, min_timestamp becomes 0 so all past identical events count as duplicates; for far-future events the window is symmetric around the event's own timestamp 🟢
- **transient-based spawn lock** — A doing_cron transient holds a microtime float; locks more than 10 minutes ahead are discarded, and WP_CRON_LOCK_TIMEOUT doubles as a one-per-minute rate limit 🟢
- **visitor-redirect fallback** — ALTERNATE_WP_CRON redirects the visitor's browser back to the same URI with a marker and runs cron during that second request, trading user latency for reliability on hosts where loopback fails 🟢
