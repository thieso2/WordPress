## Responsibilities

- **layered enablement resolution** — pre_option_enable_xmlrpc, then option_enable_xmlrpc defaulting to true, then the xmlrpc_enabled filter; the chain exists to respect back-compat filters written against the removed option 🟢
- **per-call credential authentication** — Each method receives username and password as parameters and authenticates independently, so credentials traverse the wire on every request with no built-in rate limit 🟢
