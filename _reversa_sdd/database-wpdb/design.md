## Main Flow

1. **prepare() placeholder interpolation** — sprintf-derived: strips caller quotes, escapes stray percents, preg_split with stride 3, classifies %s/%d/%f/%F/%i, checks identifier-vs-value conflicts and arity, then escapes and interpolates.
   Source: `wp-includes/class-wpdb.php:1458` 🟢
2. **placeholder escape sentinel** — Per-request hash_hmac sentinel replaces literal % in values; a query filter at priority 0 restores it just before execution, blocking second-order placeholder injection.
   Source: `wp-includes/class-wpdb.php:2413` 🟢
3. **charset upgrade cascade** — utf8 -> utf8mb4; utf8_general_ci -> utf8mb4_unicode_ci; -> utf8mb4_unicode_520_ci when the server supports it.
   Source: `wp-includes/class-wpdb.php:881` 🟢
4. **invalid text rejection** — Per-column charset and byte length are read via SHOW FULL COLUMNS and memoized; unrepresentable writes are refused rather than mangled. check_ascii() is the fast path.
   Source: `wp-includes/class-wpdb.php:3624` 🟢
5. **reconnect with backoff** — DO 1 liveness probe, then 5 retries with sleep(1); silent failure after template_redirect.
   Source: `wp-includes/class-wpdb.php:2124` 🟢

## Alternative Flows

- **BR-DB-06:** A write containing text the target column's charset cannot represent is rejected outright, never truncated. 🟢
- **BR-DB-09:** Charset utf8 is always upgraded to utf8mb4; utf8_general_ci becomes utf8mb4_unicode_ci, upgraded further to utf8mb4_unicode_520_ci when supported. 🟢
- **BR-DB-12:** $where in update()/delete() supports only equality joined with AND; no OR and no operators. 🟢
- **BR-DB-14:** If the connection is lost after template_redirect has fired, wpdb fails silently rather than emitting an error page into a partial response. 🟢

## Risks and Gaps

- 🟢 **F-DB-01** — prepare() is string interpolation, not a server-side prepared statement. Every SQL-injection defense in WordPress rests on this one regex-driven function.
- 🟢 **F-DB-02** — The 'query' filter lets any plugin rewrite every SQL statement in the system, bypassing every guard above it.
- 🟢 **F-DB-03** — $allow_unsafe_unquoted_parameters remains true for backward compatibility, preserving the historically unsafe %1$s-as-identifier pattern. The class docblock itself calls it risky.
- 🟢 **F-DB-04** — strip_invalid_text_* issues extra SHOW FULL COLUMNS queries per table on first use; correctness bought with round-trips.
- 🟢 **F-DB-05** — 5x1s reconnect sleeps inside a web request is a latency cliff under DB stress; requests queue rather than fail fast.
- 🟢 **F-DB-06** — No transaction API. wpdb exposes no begin/commit/rollback, so multi-table operations such as deleting a post and its meta are not atomic.
- 🟢 **F-DB-07** — $queries profiling only populates when SAVEQUERIES is defined, so production query analysis requires a code change.
- 🟢 **F-DB-08** — The db.php drop-in can replace this class entirely with no enforced interface contract: a 4200-line implicit interface.
