## Responsibilities

- **callback unique id** — String callbacks key by name; objects by spl_object_id; [obj,method] by spl_object_id+method; [Class,method] by Class::method; anything else returns null and is dropped 🟢
- **live iteration re-sort** — Repositions PHP's internal array pointer for each active nesting level when a hook is added during its own dispatch 🟢
- **three-branch argument dispatch** — accepted_args==0 uses call_user_func; >= num_args uses call_user_func_array with full args; otherwise array_slice. Avoids array_slice when possible 🟢
- **symlink-aware plugin basename** — arsort over $wp_plugin_paths so the longest canonical path matches first, then strips WP_PLUGIN_DIR/WPMU_PLUGIN_DIR 🟢
