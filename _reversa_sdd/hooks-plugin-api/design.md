## Main Flow

1. **callback unique id** — String callbacks key by name; objects by spl_object_id; [obj,method] by spl_object_id+method; [Class,method] by Class::method; anything else returns null and is dropped.
   Source: `wp-includes/plugin.php:1002` 🟢
2. **live iteration re-sort** — Repositions PHP's internal array pointer for each active nesting level when a hook is added during its own dispatch.
   Source: `wp-includes/class-wp-hook.php:130` 🟢
3. **three-branch argument dispatch** — accepted_args==0 uses call_user_func; >= num_args uses call_user_func_array with full args; otherwise array_slice. Avoids array_slice when possible.
   Source: `wp-includes/class-wp-hook.php:349` 🟢
4. **symlink-aware plugin basename** — arsort over $wp_plugin_paths so the longest canonical path matches first, then strips WP_PLUGIN_DIR/WPMU_PLUGIN_DIR.
   Source: `wp-includes/plugin.php:776` 🟢

## Alternative Flows

- **BR-HOOK-01:** Default priority is 10; lower runs earlier. A null priority becomes 0. 🟢
- **BR-HOOK-02:** Default accepted_args is 1. Callbacks receive a sliced argument list when they accept fewer args than passed. 🟢
- **BR-HOOK-11:** apply_filters_deprecated() emits its notice only when a callback is actually registered. 🟢
- **BR-HOOK-12:** has_filter() returns the integer priority when a specific callback is found; falsy comparison against priority 0 is a known trap. 🟢

## Observability

- BR-HOOK-03 — A callback whose unique id cannot be built is silently dropped with no error or notice. `wp-includes/class-wp-hook.php:96`
- BR-HOOK-11 — apply_filters_deprecated() emits its notice only when a callback is actually registered. `wp-includes/plugin.php:723`

## Risks and Gaps

- 🟢 **F-HOOK-01** — Actions and filters share one implementation; do_action() is apply_filters() with the return discarded. The distinction is a single boolean.
- 🟢 **F-HOOK-02** — Closures cannot practically be removed once registered because their key is spl_object_id(). Structural limitation with no core workaround.
- 🟢 **F-HOOK-03** — resort_active_iterations() depends entirely on PHP internal array pointer semantics; the most fragile code in the kernel, with no test coverage available in this tree.
- 🟢 **F-HOOK-04** — Silent failure on unbuildable callback ids means a typo'd add_filter() produces no diagnostic.
- 🟢 **F-HOOK-05** — The 'all' hook check runs on every dispatch site (~3371) even when unused.
- 🟢 **F-HOOK-06** — Because 1638 filters wrap core values, no core function's return value can be specified without also specifying its filters. The single most important constraint on writing accurate WordPress specs.
- 🟡 **F-HOOK-07** — spl_object_id reuse after garbage collection could theoretically collide two callbacks within a request; no guard exists.
