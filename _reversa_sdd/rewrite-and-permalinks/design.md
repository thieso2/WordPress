## Main Flow

1. **positional tag substitution** — Each %tag% is replaced by its regex to build the match pattern and by its query key to build the index.php?... target, using three index-aligned arrays.
   Source: `wp-includes/class-wp-rewrite.php:281` 🟢
2. **single-option rule cache** — The complete rule set is serialized into the rewrite_rules option and read on every permalink request; regeneration is triggered when the option is empty.
   Source: `wp-includes/class-wp-rewrite.php:1493` 🟢
3. **sticky deferred flush** — Flushes before wp_loaded are re-registered on wp_loaded, with a static $do_hard_later accumulating hardness via OR across all deferred callers.
   Source: `wp-includes/class-wp-rewrite.php:1873` 🟢
4. **verbose page rules** — When a structure starts with a variable tag, an explicit rule is emitted per page so pages can be distinguished from posts, making rule count O(pages).
   Source: `wp-includes/class-wp-rewrite.php:469` 🟢

## Alternative Flows

- **BR-RW-09:** A hard flush additionally writes .htaccess or web.config, but only when save_mod_rewrite_rules() / iis7_save_url_rewrite_rules() exist (admin only). 🟢
- **BR-RW-11:** With use_verbose_page_rules enabled (the default), one rewrite rule is generated per page. 🟢

## Observability

- BR-RW-08 — Deferred hard-flush requests accumulate with logical OR in a static; one hard request makes the eventual flush hard. `wp-includes/class-wp-rewrite.php:1878`

## Risks and Gaps

- 🟢 **F-RW-01** — The rewrite compiler is three positionally-aligned arrays; inserting a tag requires editing all three at the same index and nothing enforces the alignment.
- 🟢 **F-RW-02** — The entire routing table is one serialized option row read on nearly every request and subject to the autoload size heuristic; large sites can push it past 150 KB and silently de-autoload their own router.
- 🟢 **F-RW-03** — use_verbose_page_rules makes rule count O(pages), so a site with thousands of pages has a rewrite option measured in megabytes.
- 🟢 **F-RW-04** — Flush deferral to wp_loaded means flush_rewrite_rules() never does what its name says at call time, a persistent source of confusion.
- 🟢 **F-RW-05** — Hard flushes silently become soft on the front end because save_mod_rewrite_rules() is only defined in the admin.
- 🟡 **F-RW-06** — pagination_base couples this module to wp_unique_post_slug(): changing it would change which post slugs are legal.
