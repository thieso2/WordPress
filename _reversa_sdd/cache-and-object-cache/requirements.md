## Overview

A request-scoped in-memory cache designed to be transparently replaced by a persistent one via the object-cache.php drop-in. The default implementation does not persist across requests. 🟢

**Complexity:** `medium` · **Business rules extracted:** 10 · **Public functions catalogued:** 13 · **Extension points:** 0

## Responsibilities

- **multisite key prefixing** — Non-global-group keys get '{blog_id}:' prepended. The entire multisite cache isolation mechanism is a string prefix 🟢
- **null-safe existence check** — isset() OR array_key_exists() so a cached null is a hit, not a miss 🟢
- **double clone isolation** — Objects cloned on both set and get so caller mutation cannot corrupt the in-process cache array 🟢
